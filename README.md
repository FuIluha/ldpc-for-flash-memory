# Репозиторий кода для анализа и построения LDPC
## Что тут есть?

+ Алгоритм progressive edge growth для построения проверочных матриц заданного вида.
+ Bitflipping декодер.
+ Density evolution для bitflipping в двоично симметричном канале.
+ Density evolution для majority logic алгоритма для бинарного канала со стираниями.
+ Метод оптимизации differential evolution для подбора полиномов edge perspective. Использует результаты density evolution для majority logic алгоритма для бинарного канала со стираниями.
+ Много всего другого
